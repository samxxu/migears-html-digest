# P1-1 — Entity-encoded non-hidden tags survive into the output: …

## Finding / 问题

- EN: Entity-encoded non-hidden tags survive into the output: `toText("<p>&lt;b&gt;bold&lt;/b&gt;</p>")` → `<b>bold</b>`; `&lt;img src=x onerror=alert(1)&gt;` → a live `<img>` with an event handler; `&lt;a href=javascript:alert(1)&gt;x&lt;/a&gt;` → a live link. The README says the output "contains no tags … carries no injection risk".

- Where / 位置: `src/HtmlDigest.php:48-58 vs README:192,532`
